# Трекер артиста

Бесплатное мобильное веб-приложение и Telegram Mini App для планирования релиза. Это обычные HTML, CSS и JavaScript: сборка, сервер, аккаунт и платные API не нужны.

## Открыть на компьютере

Откройте `index.html` в браузере. Данные сохраняются в localStorage этого браузера и устройства. Для локального тестирования также можно запустить из этой папки `python3 -m http.server 8000` и открыть `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создайте на GitHub новый публичный репозиторий, например `tracker-artista`.
2. Загрузите в корень репозитория `index.html`, `styles.css` и `app.js` (README можно загрузить тоже).
3. Откройте репозиторий → **Settings** → **Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/(root)` и нажмите **Save**.
5. После публикации GitHub покажет HTTPS-адрес вида `https://ВАШ-АККАУНТ.github.io/tracker-artista/`. Откройте его и проверьте работу приложения.

GitHub Pages доступен бесплатно для публичных репозиториев. Не включайте платные функции, Actions или сторонние сервисы: для этого приложения они не нужны. Публикуя репозиторий публично, вы публикуете исходники, но данные пользователей остаются в их браузерах.

## Подключение Telegram Mini App

1. В Telegram открой `@BotFather`, отправь `/newbot` и создай бота. Запиши его username (заканчивается на `bot`); токен для этой статической версии не нужен.
2. Открой `/mybots` → выбери бота → **Bot Settings** → **Configure Mini App** и включи Main Mini App. Укажи название и HTTPS-адрес GitHub Pages из предыдущего раздела.
3. Чтобы открыть приложение кнопкой рядом с полем ввода, в `/mybots` выбери бота → **Bot Settings** → **Menu Button** → **Configure Menu Button**. Задай подпись, например «Открыть трекер», и тот же HTTPS-адрес.
4. Проверь запуск из чата с ботом на телефоне. Также можно включить Mini App как кнопку профиля бота в разделе **Configure Mini App**.

Создание и использование бота и Bot API бесплатны. Токен бота для этой версии не требуется: приложение статическое, Telegram SDK используется только для полноэкранного режима, цветов заголовка и кнопки «Назад». Приложение не отправляет аналитику или содержимое заметок боту. Сначала опубликуй страницу и проверь её в браузере, затем добавь URL в BotFather.

## Что умеет приложение

- Редактирование названия трека, даты релиза и заметок без сброса прогресса.
- Отдельная вкладка «Заметки»: выбор текущего или архивного трека, просмотр и редактирование его заметок, добавление нескольких подписанных ссылок-референсов и быстрый переход по ним. Заметки и ссылки хранятся отдельно для каждого трека.
- Личный кабинет артиста открывается через значок меню в шапке: псевдоним, общая аватарка и три сохранённые темы оформления — «Лимонный неон», «Electric Blue» и «Небесно-розовый».
- Подтверждение перед началом нового релиза; предыдущий трек сохраняется в архив.
- 30 отметок дней для сниппетов: можно отметить несколько дней подряд заранее или внести отметки задним числом, снять любую отметку или отменить последнюю.
- Контент-квест на 5 выполнений и квест продвижения на 3 выполнения. Повторять типы можно и перевыполнять цель; счётчик показывает все выполнения (например, 6 / 5), а отдельные выполнения отменяются по одному.
- Кнопка «Завершить план» проверяет месячную аналитику. Если отчёта нет, приложение плавно открывает форму нужного месяца; после заполнения и сохранения показателей появляется окно итогов плана и статистики площадок.
- Из окна итогов можно перейти к подтверждению нового релиза. Новый трек начинается только после отдельного подтверждения.
- Ручная аналитика за месяц: Instagram и TikTok, а также Яндекс Музыка, VK Музыка, Spotify и Apple Music с отдельными прослушиваниями и уникальными слушателями.
- Список месячных отчётов и сводное сравнение трёх последних месяцев.
- Графики динамики за последние два или три отчёта, сгруппированные по площадкам. Просмотры и прослушивания отмечены жёлтым, прирост аудитории — белым.
- После сохранения третьего месячного отчёта открывается отдельное окно итогов квартала с графиками и сравнением трёх месяцев.
- Выразительные motion-анимации: каскадное появление разделов, пружинящая отметка дней и квестов, прорисовка графиков, выразительное появление окон и лёгкое движение 30-дневного индикатора. Для пользователей с системной настройкой «Уменьшение движения» анимации отключаются.

## Хранение данных и ограничения

Все треки, отчёты, профиль и аватарка хранятся только в локальном хранилище на данном устройстве. В Telegram на одном устройстве данные разделяются по Telegram-профилю; в обычном браузере они отдельны от Telegram. Очистка данных сайта или смена устройства/браузера может удалить их; облачной синхронизации или экспорта пока нет. Данные не передаются разработчику, боту, аналитическим системам или облачной базе. Не используй приватный режим, если хочешь сохранить данные между сессиями.

Цифры в текущей бесплатной версии вводятся вручную. Автоматический импорт потребует отдельного официального подключения через авторизацию и API каждой поддерживаемой площадки.

Круглая кнопка с буквой «Т» в шапке позволяет загрузить аватарку JPG, PNG или WebP до 12 МБ. Изображение сжимается и сохраняется только в локальном браузере.

Для переноса на другое устройство потребуется отдельно настроить бесплатную синхронизацию или резервное копирование; в базовой версии нет внешнего сервиса и риска тарифицируемого использования.
